THƯ MỤC ẢNH
===========
Đặt ảnh thật vào thư mục này với đúng tên file sau, website sẽ tự hiển thị:

  slide-1.jpg     -> Ảnh slider 1 (Hồ Trị An)          - trang index.html
  slide-2.jpg     -> Ảnh slider 2 (Khu du lịch Bửu Long) - trang index.html
  slide-3.jpg     -> Ảnh slider 3 (The Amazing Bay)    - trang index.html
  hero-dacsan.jpg -> Ảnh banner trang đặc sản          - trang dac-san.html

Khi chưa có ảnh, website tự dùng nền gradient màu thay thế (không bị lỗi ảnh vỡ).
Nên dùng ảnh ngang, kích thước khoảng 1920x1080.
